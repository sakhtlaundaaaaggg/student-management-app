STUDENT MANAGEMENT WINDOWS APP - HINDI GUIDE

Features:
- Student add/edit/delete
- Search by name, roll number, mobile, class
- Dashboard counts
- CSV export
- JSON backup
- Print / Save as PDF
- Records stored locally in this Windows app profile (not cloud synced)

IMPORTANT:
1. This project is source code, not a ready-made .exe.
2. To build without installing development software on your own PC, use GitHub Actions on a Windows cloud runner.
3. The app saves records in Electron localStorage on the same Windows user profile. Keep regular JSON backups.
4. This starter project does not include login, cloud sync, automatic backup, or multi-computer sharing.
5. PDF export: Reports & Export > Print / Save as PDF, then choose "Save as PDF" in the print dialog.
